# HidePro - Lightweight Window Hider for Windows

순수 C++ / Win32 네이티브 기반의 초경량 윈도우 숨김, 보스키, 트레이 최소화 유틸리티입니다.

## 주요 기능
- **원클릭 / 단축키 윈도우 숨김**: 작업표시줄 및 화면에서 특정 창 또는 전체 창을 즉각 숨김/복원
- **보스키(Boss Key)** 지원: 긴급 상황 시 모든 윈도우 즉시 은닉
- **시스템 필수 창 보호**: 작업표시줄, 데스크톱 등 OS 핵심 UI 자동 필터링
- **트레이 아이콘 연동**: 백그라운드 트레이 상주 및 빠른 토글 메뉴 제공
- **의존성 0%**: 외부 DLL 설치 없이 단일 실행 파일로 즉시 구동

## 배포 및 설치
- **설치 프로그램 (`HidePro_Setup.exe`)**: EasyInstall 기반 UAC 관리자 권한 자동 설치, 바탕화면/시작 메뉴 바로가기 및 언인스톨러 등록
- **포터블 버전 (`HidePro_v1.0.0_Portable.zip`)**: 무설치 단일 실행 파일 압축본
